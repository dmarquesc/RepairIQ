GPU Health / Thermal

Prioritize threshold failures and correlate heartbeat, thermal, power, and test symptoms before recommending hardware isolation.

Prototype logic Rule SXM-GPU-001

PCIe / Link State

Verify configuration and physical state, reseat when appropriate, retest, then isolate the device or slot before replacement.

Prototype logic Rule SXM-PCI-002
FW

Firmware State

Identify platform and configuration first. Firmware actions require version validation and qualified technician approval.

Review required Rule SXM-FW-003

Check tester state, permissions, calibration, environmental conditions, and repeatability before replacing hardware.
